Kubermatic provides a multi‑cloud Kubernetes management platform that enables enterprises to deploy, operate, and scale Kubernetes clusters across any infrastructure—public clouds, on‑premises data centers, and edge environments. The solution includes automated provisioning, lifecycle management, security controls, and integrated AI‑driven optimization for workloads. Kubermatic is recognized in the 2026 Gartner Magic Quadrant for Container Management and offers products such as Kubermatic Kubernetes Platform, Kubermatic AI, KubeLB, and SecureGuard.

**Areas:** Company · Kubernetes · Multi-Cloud · Platform · Artificial Intelligence

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Kubermatic: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
